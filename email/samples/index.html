Voucher email — static samples

Each file is the complete email as it would arrive in the inbox, with every %variable% already filled (Sarah Tan ← James, Christmas Eve Dinner Buffet at StraitsKitchen, code GH-8F3K-2Q7M, ref GH12345678).

Design “Luxe Ticket” (v2, spec email/DESIGN-TICKET.md): the message sits on cream paper (layout varies), then a horizontal voucher ticket in the card colour with a thin gold inner frame, the voucher name in large serif type and a cream stub holding the QR (always on white) and the code. Below: “View your gift online”, How to redeem (3 steps), Good to know (short terms + link) and “Purchased on … · Ref …”. The long voucher description now lives on the gift page.

Images use relative paths (../../assets/img/…) for local review only. For a real test send, every image (banner, logo, QR) must be an absolute https:// URL.
Overlay and split point at the original 1200×900 photos; in production the backend must pre-crop them (overlay exactly 592×460, split 416×600) — email clients cannot crop. QR here is a sample PNG (assets/img/qr-sample.png); the real %qr_code% must also be a PNG/JPG <img> (~120px, never SVG — many clients block it).
Regenerate: node email/samples/build.js. Interactive preview (layouts, colours, Gmail/Outlook simulation): email/preview.html.
